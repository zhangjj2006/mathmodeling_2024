2. 特征重要性分析揭示了各因素对达标时间影响的相对强度
3. 模型验证表明，引入年龄、身高、体重等因素能够显著提高预测准确性

5. 不同BMI分组中，各因素的影响程度存在差异，需要个性化考虑
6. 使用线性插值法更精确地估计了Y染色体浓度达到4%的时间点
7. 对于样本量较少的聚类4，使用线性回归作为替代方法，仍能提供有用的预测
