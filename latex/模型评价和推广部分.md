# 模型评价和推广部分

## 模型的优点

问题2：

1. 采用 **K-means聚类算法** 对孕妇BMI进行客观分组，通过轮廓系数、DBI指数和CH指数等多指标评估聚类效果，确保分组的合理性与解释性。
2. 引入 **Kaplan-Meier生存分析** 构建累积达标函数，处理右删失数据，更准确地描述不同BMI组别随时间变化的达标规律。
3. 结合 **动态效用函数**，融合早期与晚期风险（如早检风险递减、晚检风险递增），通过 **有界优化算法（minimize_scalar）** 求解最优检测时间，使模型输出兼具统计最优性与临床可解释性。
4. 通过 **蒙特卡洛模拟（Monte Carlo Simulation）** 模拟检测时间误差，分析其对最优时点、效用值与风险水平的影响

问题3： (3和2有很多重复，这里写新的)

1. 采用了**随机森林回归与线性回归的对比建模策略**，以全面评估不同算法在预测达标时间上的性能差异。针对样本量充足的BMI分组，采用**随机森林回归**（RandomForestRegressor）捕捉年龄、身高、体重与达标时间之间潜在的非线性关系和交互效应；对于样本量较少的分组，则采用**线性回归**（LinearRegression）保证模型稳定性。

2. 为严格评估模型性能与泛化能力，本研究实施了**K折交叉验证**（KFold），根据样本量动态调整折数（n_splits=min(5, len(X))），综合使用**R²得分**和**平均绝对误差（MAE）** 作为评估指标。通过对比"仅使用平均值预测"与"使用完整模型预测"的MAE，量化了引入影响因素后预测精度的提升幅度，证明了多因素建模的有效性。

3. 引入**SHAP（SHapley Additive exPlanations）价值分解**技术，通过量化年龄、身高、体重对预测达标时间的边际贡献，不仅识别出关键影响因素，更揭示了其作用方向与强度，显著提升了模型的透明度与临床可信度。



## 模型缺点

1. **数据依赖性强**：模型的输入依赖于“预测达标天数”等关键字段，其准确性直接影响最终结果。若初始预测数据存在系统性偏差，模型的推荐结果也将产生偏差。

2. **效用函数定义依赖假设**：模型中早期风险函数（`get_rearly`）和晚期风险函数（`get_rlate`）的具体形式基于假设设定。虽然符合临床直觉，但其精确的参数（如衰减系数50、分段点84/189天）需要通过更深入的临床研究或专家经验进行校准，以更真实地反映实际风险。

3. **聚类分组固定**：模型采用K-means对BMI进行硬聚类，得到了5个固定区间。这种方法虽然简洁，但可能忽略了区间内部差异以及处于边界附近的个体的特性。

4. **样本量不平衡问题**：部分BMI分组（如高BMI组）样本量相对较少，导致在其上训练的预测模型稳定性较差。
